# Crozier Church Admin

React, TypeScript, Vite, and Tailwind frontend for the church admin dashboard.

## Run locally

```sh
npm install
npm run dev
```

The app currently uses local mock data for its screens.

## Checks

```sh
npm run lint
npm run build
```

Main routes: `/dashboard`, `/units`, `/units/:unitId`, `/admin-users`, `/settings`, and `/profile` (linked from the sidebar footer).
